# Shwe Moe Thant (Aurum) Portfolio Website

This is a self-contained one-page portfolio website built from the updated CV.

## Files
- `index.html` - main website file
- `assets/ShweMoeThantCV_Aurum.pdf` - downloadable CV PDF
- `assets/ShweMoeThantCV_Aurum.docx` - downloadable Microsoft Word CV

## Important deployment note
Upload the whole folder to GitHub Pages, including the `assets` folder. The download buttons use direct static links, so the files must exist at:

- `assets/ShweMoeThantCV_Aurum.pdf`
- `assets/ShweMoeThantCV_Aurum.docx`

If only `index.html` is uploaded, the CV download will fail.
